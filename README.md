# Robotics and RGB LEDs

## What is Robotics?

**Robotics** is a branch of engineering and computer science that focuses on designing, building, and programming *intelligent machines* capable of performing tasks automatically or semi-autonomously.

## Understanding RGB LEDs

- **What is an RGB LED?** A special light-emitting diode that combines three tiny lights inside one bulb to produce millions of different colors.
- **What does RGB stand for?** It stands for **Red, Green, and Blue**.
- **Changing Colors with Python:** On mBot2, we use `cyberpi.led.on(r, g, b)` by setting values from `0` to `255` for each color channel.
- **Turning Off All LEDs:** When we set all values to `(0, 0, 0)` or use `cyberpi.led.off()`, no light is emitted and the LEDs turn completely dark.

## Three Examples of Robots in Everyday Life

1. **Robotic Vacuum Cleaners:** Navigate homes autonomously to clean floors.
2. **Industrial Assembly Arms:** Build cars and electronics with high speed and precision in factories.
3. **Medical Surgical Robots:** Assist doctors in performing delicate and minimally invasive surgeries.
